# Native MediaHost reference (iOS / Android)

The gossamer mobile media capabilities (`shell.Camera` / `shell.Audio`) are pure
Go in `shell/mobile` and fully tested headless (`media_test.go`). The only
platform-specific part is a thin **native `MediaHost`** that the host project
registers on the Bridge: Go calls it to start captures; the host reports results
back via the Bridge's `Deliver*` / `Set*` / `Fail*` methods, correlating by
`reqID`.

The Swift and Kotlin files here are **reference scaffolding** — copy them into
the host project generated by `gossamer create` and verify on device. The exact
gomobile-generated type names (`Mobile.Bridge`, the `MediaHost` protocol/
interface, method casing) depend on your `gomobile bind` package; adjust to match.

## Contract

Go → native (you implement): `AuthorizeCamera`, `CapturePhoto`, `AuthorizeMic`,
`StartRecording`, `StopRecording`, `PlayClip`, `SeekPlayback`, `StopPlayback`.

Native → Go (you call on the **UI thread**): `DeliverPermission`,
`DeliverPhoto`(JPEG/PNG bytes) / `FailCapture`, `DeliverRecorderReady` /
`FailRecording`, `SetAudioLevel`(0..1), `DeliverPCM`(16-bit **LE mono** + sample
rate + durationMs), `DeliverPlaybackReady`, `SetPlaybackPosition`(ms),
`PlaybackEnded`.

Recording delivers **raw PCM**; Go encodes the portable WAV `Clip` with
`shell.EncodeWAV`, so the clip is byte-identical in shape to the web shell's.
Playback receives that WAV via `PlayClip`.

**Threading:** every `Deliver*`/`Set*`/`Fail*` call must be on the host UI thread
(it runs app callbacks that mutate the widget tree). Marshal background capture
callbacks (audio taps, camera completion) to the UI thread first.

## Permissions

- **iOS `Info.plist`:** `NSCameraUsageDescription`, `NSMicrophoneUsageDescription`.
- **Android `AndroidManifest.xml`:** `<uses-permission android:name="android.permission.RECORD_AUDIO"/>`
  (camera via the capture intent needs no `CAMERA` permission). Request
  `RECORD_AUDIO` at runtime before `StartRecording`.

`gossamer create` should inject these into the scaffolded projects.
